👩‍💻 Personal portfolio site built with Next.js + TypeScript

This repository contains a small high-performance, SSR-first portfolio site showcasing TypeScript, React, and server-rendered pages.

Quick start

```bash
# install deps
npm ci

# run dev server
npm run dev

# build for production
npm run build

# typecheck
npm run type-check
```

What's included

- TypeScript-ready Next.js pages (`pages/*.tsx`)
- SSR-friendly data via `getStaticProps`
- Simple CSS, accessible layout, and minimal client JS for snappy UX

You can customize `data/projects.ts` with your real projects and links.
